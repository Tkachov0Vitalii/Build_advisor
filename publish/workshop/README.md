# Build Advisor — Steam Workshop workspace

Upload with the official Mega Crit uploader (https://github.com/megacrit/sts2-mod-uploader):

    ModUploader.exe upload -w BuildAdvisor-workshop

- `content/` — the mod files (generated by the release script from the build).
- `workshop.json` — title, description (Steam BBCode), visibility, change note.
- `image.png` — preview, 512×512, < 1 MB. `previews/` — extra screenshots.
- `mod_id.txt` — Workshop item id (3832174623, https://steamcommunity.com/sharedfiles/filedetails/?id=3832174623); the release script copies it so `upload -w` updates the same item.
