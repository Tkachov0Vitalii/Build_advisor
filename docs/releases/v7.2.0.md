# Build Advisor 7.2.0

## Highlights

- **Skip advice that actually happens.** Spire Codex lift is a correlation: the average card shows about +7 pp, so measuring cards against zero advised "take" on 99.8 % of corpus rewards (players skip 32 %, winners 37 %). Cards are now measured from the *typical pick* — the card players take in this act at this deck size — and a high learned skip probability (model on 1.7 M decisions) raises the bar.
- **Calibrated on 177k runs** (2,184,681 rewards incl. skips): parameters fitted on train to advise skipping about as often as winners skip. Validation / test: skip advised in 36.9 % / 36.2 % of rewards (winners skip 37.4 % / 36.6 %; 7.1: 0.2 %); agreement with winners' choices 33.6 → 44.2 % / 34.2 → 44.7 %. Where 7.1 and 7.2 disagree, runs that did what 7.2 says won 43.9 % vs 28.9 % (validation), 47.8 % vs 32.2 % (test) — an association, not proof (stronger players skip more).
- Ribbons, summary and breakdown show pp **vs a typical card**; the breakdown also shows the raw lift. Auto-pick follows the new verdict.
