# Build Advisor 7.0.0

The first release prepared for Steam Workshop, Nexus Mods and GitHub.

## Highlights

- **Parchment interface** — the wax seal **BD** at the left edge (or **F8**) opens a 640 px panel on the left; the game stays visible.
- **Summary on top** — a verdict ("Take …", "Better skip", "Best buy", "Relic", "Upgrade …"), confidence, ranked options with coloured tiers, score bars and the win-rate change, deck needs and archetypes; the detailed breakdown below.
- **Coloured tiers** — S purple, A red, B amber, C blue, D grey on every ribbon; dark ink of the same hue (contrast ≥ 7:1); the best option is framed in gold with ★.
- **Calibrated scoring** (6.23) — deck adjustments weighted by an outcome regression on 177,251 runs / 1.6 M card rewards; held-out check: where old and new picks differ, runs that took the new pick won 35.2 % vs 33.4 % (test), 33.5 % vs 29.7 % (validation).
- **Co-op** (6.23) — teammates' decks, roles and archetypes.
