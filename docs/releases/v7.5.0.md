# Build Advisor 7.5.0

Statistics and models for **Major Update #3 (game v0.111.1)**. Includes 7.4.0 (Ancient relics valued per act, verified relic synergies), which was not published separately.

## Statistics of your game version

Spire Codex statistics without a version mix every patch since early access. The mod now reads the game version and asks for that version's slice (`a10:v0.111.0` for game v0.111.1: the beta with the same content, 206k A10 runs). If the version has no slice with at least 20,000 A10 runs, it takes the previous version of the same line, then the newest older one, then all versions as before. The card panel names the version in use. Example: Demon Form was −5.1 pp on v0.107.1 and +9.5 pp on v0.111.0.

## Models refitted on v0.111.x runs

174k runs of v0.111.0 / v0.111.1 (1.6 million card rewards):

- **Take or skip** thresholds: advised skips per act 24 / 41 / 55 % on held-out runs, winners 24 / 42 / 55 %. C# replay on 10k v0.111.1 runs: 22 / 37 / 50 % vs winners 25 / 39 / 50 %.
- **Ancient relics**: held-out correlation 0.89, top-vs-bottom-third gap 7.9 pp. New and changed Ancient relics (Neow's Sacrifice, Toasty Mittens, Diamond Diadem…) are valued per act again.
- **Relic × card synergies**: Mummified Hand × Powers +2.3 pp, Red Mask × Weak cards −2.8 pp. Game Piece × Powers (7.4) did not hold on v0.111.x and was removed.
