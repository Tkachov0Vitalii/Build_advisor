# Проверка модели Build Advisor 6.15

Дата проверки: 2026-09-21.

## Данные

- 177 248 валидных забегов и 2 132 320 решений по картам;
- train: 140 216 забегов;
- validation: 19 390 забегов;
- test: 17 642 забега;
- разделение выполнено по анонимной группе игрока, чтобы решения одного игрока не попадали одновременно в обучение и test.

## Решение «взять или пропустить»

Модель обучена на 1 697 565 train-решениях. Порог 24% выбран только на validation и без изменения применён к test.

| Метрика | Старое правило, test | Модель 6.15, test |
|---|---:|---:|
| Balanced accuracy | 57,84% | 70,36% |
| Recall пропуска | 53,09% | 70,43% |
| Recall взятия | 62,59% | 70,29% |
| Общая accuracy | 60,44% | 70,32% |

## Безопасность автовыбора

Порог автовыбора подбирался только на 226 563 validation-решениях: оценка карты ≥90, отрыв ≥20, вероятность пропуска ≤11%. На 208 192 test-решениях:

- охват: 1,53% (3 188 решений);
- совпадение с фактическим решением: 66,72%;
- совпадение среди случаев, где игрок взял карту: 69,04%;
- исторический пропуск среди срабатываний: 3,36%.

Совпадение с историческим игроком не является доказательством оптимальности или победы. Поэтому автовыбор остаётся отключённым по умолчанию и использует существенно более строгие ограничения, чем обычный совет.
