# Памятка перед публикацией

Публикуйте `BuildAdvisor-7.2.0.zip` (GitHub Releases, Nexus Mods) и `BuildAdvisor-7.2.0-workshop.zip` (Steam Workshop); как именно — `publish/README.md`.

1. Сверьте SHA-256 с `SHA256SUMS.txt`.
2. Укажите совместимую версию игры и реально протестированные ОС.
3. В архиве уже есть обе инструкции, `LICENSE`, `THIRD_PARTY_NOTICES.md` и лицензии шрифтов.
4. Картинки для страниц: `publish/workshop/image.png` (512×512), `docs/images/logo.png`, `docs/images/reward-screen.jpg`.
5. Напишите, что сеть нужна для свежих агрегатов Spire Codex, но локальная модель и кеш работают офлайн.
6. Не публикуйте сырые забеги, сохранения, логи, Steam ID, пользовательский кеш или DLL игры.
7. Для баг-репорта просите версию мода/игры, ОС, `godot.log`, скриншот и шаги — шаблон есть в GitHub Issues.

> Build Advisor — RU/EN советник по сборке колоды для Slay the Spire 2. Оценивает награды, магазин, реликвии, костёр, события и маршрут с учётом колоды; показывает понятную формулу; на spire-codex.com уходят только состав колоды, реликвии и предложенные карты, без сохранений, Steam ID и личной истории.
